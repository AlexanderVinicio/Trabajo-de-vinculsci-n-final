Instrucciones: 

Realizar el siguiente circuito y ejecuta el programa propuesto.

Materiales:

·       Arduino Uno

·       Buzzer

·       3 botones

·       Cables jumpers

·       Protoboard

Orientaciones para docente:

Antes de iniciar con la evaluación, explique a los estudiantes que:

·       Los botones sirven para dar órdenes al Arduino.

·       El Buzzer responde mediante sonidos.

·       Cada botón produce un sonido diferente.

 Procedimiento: 

1. Guiar a los estudiantes al armado del circuito según la imagen

 

 

 

2.     Proporcionar el código base

void setup()

{

  // Configuración de los pines

  pinMode(A0, INPUT);  // Pin A0 como entrada (pulsador 1)

  pinMode(A1, INPUT);  // Pin A1 como entrada (pulsador 2)

  pinMode(A2, INPUT);  // Pin A2 como entrada (pulsador 3)

  pinMode(8, OUTPUT);  // Pin 8 como salida (buzzer o parlante)

}

void loop()

{

  // Si se detecta que el pulsador conectado al pin A0 está presionado

  if (digitalRead(A0) == HIGH) {

    tone(8, 440, 100); // Emite un sonido de 440 Hz (nota LA) durante 100 ms

  }

  // Si se detecta que el pulsador conectado al pin A1 está presionado

  if (digitalRead(A1) == HIGH) {

    tone(8, 494, 100); // Emite un sonido de 494 Hz (nota SI) durante 100 ms

  }

  // Si se detecta que el pulsador conectado al pin A2 está presionado

  if (digitalRead(A2) == HIGH) {

    tone(8, 523, 100); // Emite un sonido de 523 Hz (nota DO) durante 100 ms

  }

  // Pequeña pausa para mejorar la estabilidad de la lectura

  delay(10);

}
